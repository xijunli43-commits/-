# 方案、先例与验证

## 已审阅的先例

需求阶段查看 [GSMArena 对比](https://www.gsmarena.com/compare.php3) 与 [NanoReview 手机列表](https://nanoreview.net/en/phone-list)，采用列表筛选、详情、少量机型并排对比的常用流程，不复制第三方页面和图片。

界面采用 Apple 标准 SwiftUI 导航、TabView 和原生玻璃控件，内容区域保持可读：[Liquid Glass 总览](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)、[自定义控件](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)、[官方示例](https://developer.apple.com/documentation/swiftui/landmarks-building-an-app-with-liquid-glass)。Windows 无法验证原生渲染，交付源码而非声称已生成 IPA。

架构阶段审阅了 [XcodeGen](https://github.com/yonaskolb/XcodeGen)、[项目规范](https://github.com/yonaskolb/XcodeGen/blob/master/Docs/ProjectSpec.md)、[Flask 的 Waitress 部署](https://flask.palletsprojects.com/en/stable/deploying/waitress/)。复用原 PWA 数据与网页预览；新建原生 SwiftUI 视图，组合现成 HTTP 服务、SQLite、Requests、Beautiful Soup。没有引入完整 CMS，因为原包具有嵌套且不统一的规格模型，需要成绩版本、人工机型匹配和草稿发布流程。

采集阶段审阅 [安兔兔公开榜单](https://www.antutu.com/ranking)、[Geekbench Browser](https://browser.geekbench.com/)、[Geekbench Browser Python](https://github.com/34j/geekbench-browser-python)。最后一个项目主要处理聚合处理器接口，不满足本项目手机单条成绩审核，因此没有复制代码或增加依赖。定制适配器只解析受支持页面的实际字段，遇到变化报错；第三方页面结构不是稳定 API。

调试阶段检查现有测试、[SQLite 连接生命周期](https://docs.python.org/3.13/library/sqlite3.html) 和 [Requests 编码说明](https://requests.readthedocs.io/en/latest/user/quickstart/)。修复连接未关闭、更新导致记录重排和中文编码问题；审核应用与状态标记放入同一事务，阻止重复审核覆盖。

## 依赖成本与许可

Flask（BSD-3-Clause）、Waitress（ZPL-2.1）、Requests（Apache-2.0）、Beautiful Soup（MIT）均为已有维护的通用库；SQLite 是 Python 自带数据库。采用安装时可获得的固定版本，完整运行锁文件见 backend/requirements.txt。XcodeGen（MIT）仅用于 Mac 生成工程。iOS 无第三方运行依赖。未复制上述开源项目源代码；分发第三方安装包时仍须保留各自许可。后续升级需要重新检查兼容性与漏洞。

## 验证记录

- 原始数据导出核对：182 手机、80 芯片，与上传包一致；未逐条核实事实或版权。
- 后端 9 项自动测试覆盖草稿隔离、发布、版本冲突、访问限制、CSRF、白名单、成绩版本、无效页拒绝、规格保留、删除恢复和 ETag。
- 浏览器实际打开管理后台，搜索、打开编辑并保存原值，采集安兔兔、查看候选差异；未自动覆盖已发布成绩。
- 实际安兔兔页面解析得到 127 条，页面统计期为 2026 年 8 月。采集时间不意味着榜单统计期是当天。
- Geekbench 实际自动请求遭网站拦截；解析器使用样例验证，正常真实网页兼容性尚未充分验证。
- iOS 源码、plist、资源已静态检查，Swift XCTest 提供但未执行；没有 Mac/Xcode，无法声称编译、模拟器、签名、App Store 成功。
- 后台截图为 release/admin-preview.jpg。局域网模式已做接口权限测试，未在真实 iPhone 上连接。

搜索渠道覆盖本地源码、已安装技能/工具、官方文档、GitHub 先例和 Python 包安装。没有取得数据授权证明；没有 Apple 构建环境。自定义代码只承担数据模型、解析适配、审核发布与界面业务。
